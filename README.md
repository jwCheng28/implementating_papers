## Quickstart

1. **Clone the Monorepo:**
   ```bash
   git clone https://github.com/jwCheng28/implementating_papers
   cd paper-implementations
   ```

2. **Running an Architecture:**
   Navigate directly into specific model subfolder under `implementations/` and follow the readme or jupyter notebook.
