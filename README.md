# Paper Implementations

This repository serves as a hub for my deep learning studies. My goal is to read DL research papers and replicate their model architectures using **PyTorch** and **PyTorch Lightning**.

## Quickstart

1. **Clone the Monorepo:**
   ```bash
   git clone https://github.com/jwCheng28/implementating_papers
   cd paper-implementations
   ```

2. **Install Python packages:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Running an Architecture:**
   Navigate directly into specific model subfolder under `implementations/` and follow the readme or jupyter notebook.
